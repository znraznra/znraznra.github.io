## Headings, lists, and code work as expected

Because this is standard Markdown, you get all the usual building blocks:

- Bulleted lists
- **Bold** and _italic_ text
- Inline `code`

```js
console.log("and fenced code blocks with syntax highlighting");
```

> Blockquotes are styled too, for pulling out a quote or an aside.

Write the way you normally would — the CMS editor above just turns this into
saved Markdown files in `_posts/`.
